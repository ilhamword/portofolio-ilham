Competency Match System

Challenge & Context

The Problem

At PT PLN (Persero) headquarters, managing human resource development across nationwide business units involves assessing employee competencies against dynamic role standards.

Because raw competency logs span over 100,000 rows across multiple divisions and positions, performing manual comparisons between current competencies and target role requirements was time-prohibitive, error-prone, and incapable of uncovering strategic career progression pathways at scale.

Scale & Processing Hurdles
  • 100K+ rows of raw competency data stored across heterogeneous spreadsheets
  • Combinatorial matching generating millions of comparative evaluations
  • Inconsistent naming codes hindering automated gap scoring

Processing Architecture

Workflow & Data Flow

The data pipeline ingests large-scale raw spreadsheets, standardizes competency taxonomies, runs cross-job matching, and generates structured gap analytics.

01 / SOURCE
Raw Excel Ingestion Loads 100K+ rows of raw employee competency logs from multiple divisional files. 100K+ Records
02 / CLEANING
Taxonomy Cleaning Deduplicates, validates codes, and normalizes skill naming across business units. Pandas Pipeline
03 / TRANSFORMATION
Matrix Restructuring Pivots and reshapes flat datasets into relational arrays for optimized comparison. Matrix Arrays
04 / MATCHING
Cross-Role Matching Evaluates actual vs required levels, processing 485K rows per grade up to 7–8 Million across all grades. 7–8M Combinations
05 / ANALYSIS
Gap Delta Scoring Calculates delta gaps (-1, -2, match) and scores target position suitability. Gap Delta Scoring
06 / EXPORT
Flexible Dual Export Outputs structured Excel (.xlsx) per grade or writes directly to MySQL database in batches to support up to 7–8M rows. Excel & MySQL (7-8M)

Technical Approach

The Solution

An automated Python data processing pipeline that programmatically ingests raw competency logs, reconciles disparate naming conventions, and executes batch matrix comparison routines.

Instead of evaluating employees one by one against a single predetermined job role, the system performs broad matrix evaluations across alternative roles within the job family — pinpointing the exact competencies requiring upskilling while highlighting optimal career path matches based on current competencies.
