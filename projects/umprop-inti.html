Internship Project — PT INTI (Persero)

UMPROP Internal System

Redevelopment of a core internal operational system at PT INTI (Persero), modernizing legacy data workflows through relational database design, automated Excel ingestion, dynamic column mapping, and server-side processing pipelines.

Challenge & Context

The Problem

The existing internal process at PT INTI relied heavily on manual data entry and decentralized spreadsheets to log operational records, project milestones, and resource allocations.

Without automated ingestion and validation pipelines, consolidating periodic reports required significant manual effort to reformat columns, cross-verify data integrity, and resolve formatting inconsistencies across departmental submissions.

Operational Pain Points
Manual data copying between disparate spreadsheets prone to human error
Inconsistent spreadsheet column structures causing ingestion friction
Time-consuming manual report compilation during operational cycles
Role & Responsibilities

My Contribution

I focused on restructuring data workflows, designing relational database tables, implementing Excel import modules, and developing backend business logic.

Database Schema Design

Designed normalized relational tables with proper primary keys, foreign keys, and indexes
Structured data models to accommodate variable operational attributes and audit logs

Excel Import Engine

Built automated file parsers to read and ingest multi-sheet Excel files
Implemented strict data type validation and anomaly detection prior to database insertion

Checklist Ruangan QR Code

Developed algorithmic mapping routines to translate dynamic Excel headers into database entities
Created transformation handlers to harmonize date formats, currency values, and category codes

Logika Hak Akses & Pelaporan

Wrote backend controllers and services executing transactional data storage
Implemented automated query routines to generate structured summary reports for management
End-to-End Workflow

Workflow & Data Flow

The automated pipeline replaces manual data handling with a 5-stage automated ingestion, mapping, storage, and reporting workflow.

01 / UPLOAD
Excel Upload & QR Scan Ingests task templates from Excel or captures field inspections via mobile QR Code scans. Excel & QR Mobile
02 / VALIDATE
Parse & Validate Verifies data types, cell integrity, and checks user authorization per assigned role. Validation Rules
03 / MAPPING
Auto Data Mapping Automatically maps checklist tasks to designated rooms, roles, and time frequencies. Mapping Engine
04 / STORAGE
Database Storage Inserts validated records transactionally into MySQL tables with audit timestamps. MySQL Database
05 / REPORT
Automated Reports Aggregates performance logs and exports structured Excel (.xlsx) summaries for leadership. Instant Excel Export

Technical Implementation

The Solution

The redevelopment established a standardized data ingestion layer that automatically interprets varying spreadsheet formats and maps columns directly to relational schema definitions.

By consolidating data into a normalized database structure, the system ensures single-source-of-truth integrity while significantly cutting down the operational overhead required to compile and produce periodic reports.
