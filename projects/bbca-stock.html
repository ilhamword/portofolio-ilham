Challenge & Context

The Problem

Stock price prediction in the banking sector is inherently challenging because price movements are influenced not only by past technical indicators and trading volume, but also heavily impacted by public market sentiment and financial news releases.

Conventional forecasting models often rely exclusively on historical numerical sequences (OHLCV). When significant macro-economic announcements or quarterly earnings reports surface, purely numerical models fail to react in time because they lack context from unstructured text data.

Core Limitations Addressed
Pure historical price models ignore market sentiment dynamics
Unstructured news text is difficult to feed directly into numerical predictors
Single-day forecasts provide limited strategic foresight for decision-making

End-to-End Architecture

Workflow & Data Flow

The data moves sequentially from automated ingestion through NLP sentiment scoring and time-series neural network forecasting into a centralized MySQL database and Flask UI.

01 / INGESTION
Dual-Source Collection Fetches OHLCV stock data from Yahoo Finance and news headlines from Google News RSS. Yahoo Finance + RSS
02 / NLP PIPELINE
Text Preprocessing Cleans, normalizes, and transforms raw Indonesian text headlines using TF-IDF feature extraction. TF-IDF Vectorizer
03 / SENTIMENT
Sentiment Scoring Classifies each news article (Positive, Neutral, Negative) using Logistic Regression. Logistic Regression
04 / STORAGE
Feature Aggregation Aggregates sentiment by date, merges with price matrices, and saves records into relational database. MySQL Database
05 / MODELING
LSTM Forecasting LSTM model trained on multi-feature sequences to project prices across H+1, H+3, H+5, H+7. LSTM Neural Net
06 / PRESENTATION
Flask Web Interface Serves interactive multi-horizon charts, recent sentiment breakdowns, and historical logs. Flask Web App

System Architecture

The Solution

The final solution is a modular application built in Python and Flask that automates the entire lifecycle of stock price analysis. Instead of relying purely on isolated statistical indicators, the system integrates daily sentiment polarity as an additional time-series dimension alongside conventional price signals (closing prices, moving averages, volume).

By supporting multi-horizon forecasting (H+1, H+3, H+5, H+7), the system provides flexible short-term and medium-term visibility, enabling users to evaluate forecasted trends over different time intervals accompanied by contextual news feeds.
